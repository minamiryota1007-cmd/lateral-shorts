# ラテラルシンキング V4 — たばこ・税金編

## 使い方（Windows PowerShell）

VOICEVOXアプリを起動した状態で以下を実行。Pixabay APIキーは環境変数 `PIXABAY_API_KEY` に設定（秘密情報はGitHubに保存しない）。

```powershell
$url = "https://raw.githubusercontent.com/minamiryota1007-cmd/lateral-shorts/main/windows_shorts_v4.py"
$file = "$env:USERPROFILE\windows_shorts_v4.py"
Invoke-WebRequest -Uri $url -OutFile $file
& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" $file
Start-Process "$env:USERPROFILE\lateral_shorts_v4.mp4"
```

## 変更したこと

- VOICEVOX「青山龍星」の標準スタイルをAPIの話者一覧から選択（番号決め打ちを回避）。不足していたらエラーで案内。環境変数 `VOICEVOX_SPEAKER` で上書き可能。
- 音声は自然な速度1.02、やや低めのピッチを使用。
- 読み上げは「ひとはこ」に指定し、画面には「1箱」と表示。字幕は算用数字で記述し、音声用テキストと分離。
- たばこの映像素材（検索語：cigarette smoking tobacco smoke close up）を優先し、税金のシーンを追加。
- 背景動画は9:16へ中央クロップして縦長に引き伸ばさない。
- 1箱600円で1日1箱・365日・10年 → 2,190,000円。紙巻たばこ20本入りの「たばこ税等」304.88円/箱（消費税を含まない）→ 約111万円/10年。税込み支出額219万円に111万円を加算してはいけない。税は商品価格に含まれる。
- 背景動画を取得できなければ写真モーションに切り替わる。実写動画そのものをAIで生成する機能ではない。
- 動画の尺はナレーションの長さに合わせ、基本30秒。音声が長いときは無理に早口にしない。

## 数字の根拠・表現

たばこ税等の金額は財務省の資料（2026年4月現在の代表的な紙巻たばこの20本あたりの税率）を参考にした推定。1箱600円という価格は説明用の仮定。銘柄により実際の販売価格は異なる。たばこ税・たばこ特別税・都道府県/市町村たばこ税を合計した304.88円であり、消費税は別。税金は消費者が別途追加で納税するものではなく価格に内包される。

ソース：https://www.mof.go.jp/tax_policy/summary/consumption/d09.htm

## 編集ディレクション用プロンプト

「30秒、縦型1080×1920、30fps。大人向けのドキュメンタリー調。低音の落ち着いた男性ナレーションで、静かに問題提起する。コンビニ・たばこ・ライター・煙・財布・現金・税金・旅行の実写背景を使う。『2,190,000円』『たばこ税等 約111万円』などを大きな算用数字で表示し、前提条件と計算式を併記する。字幕はナレーションとは別の画面用テキストとして設計し、毎日1箱を『ひとはこ』と自然に読む。無理な早口や不必要な点滅を避ける。たばこ税等は価格に含まれることを明記し、高額な税負担の事実から『その支出をどう捉える？』という問いにつなぐ。税負担を称揚も非難もしない。使える合法な実写素材だけを使用し、無料素材がないときは写真のパン/ズームに切り替える。品質レポートは不要、ただし最低限の生成エラーは停止させる。」
