# ラテラルシンキング｜次元のマグナム弾（V8）

45秒（1350フレーム）、9:16、30fps、VOICEVOX男性声、数値を大きく表示するフェルミ推定ショートのWindows制作プロジェクト。

## 実装内容
- **0–7秒**: ガンマン・回転式拳銃のCG/VFX、素手で捕まえるのは不可能と提示
- **7–16秒**: 弾丸10.2g、初速330m/s、運動エネルギー約555Jの計算式
- **16–25秒**: 上昇する弾丸と減速メーター
- **25–35秒**: 空気抵抗モデルによる約500〜1,100mの高度レンジ、進行グラフ
- **35–45秒**: 完全な鉛直飛翔の最高点では鉛直速度0m/s、その後の落下や回転を含め安全な捕獲は不可能と説明
- 安全なCG/VFXのみ。実射・捕獲は絶対に行わない。

## インストール済みならPowerShellで一括実行

VOICEVOXを起動した状態でリポジトリの\`v8\`フォルダに移動し、次を実行：

\`\`\`powershell
powershell -ExecutionPolicy Bypass -File .\run_windows.ps1
\`\`\`

- Node.jsとPython 3.13が必要。 \`npm.cmd\` と \`npx.cmd\` を使うのでPowerShell 5.1のnpm.ps1実行ポリシーによるブロックを回避。
- Pythonライブラリ \`requests\`、および実写ストック素材を取り込む場合は \`imageio-ffmpeg\` が必要。
- VOICEVOXエンジン http://127.0.0.1:50021 を事前に起動しておく。
- \`PIXABAY_API_KEY\` をPC内の環境変数に設定すると、5章に合う動画素材の自動検索・保存を試みる。**キーをコードやGitHubに直接書かないこと。**
- Pixabayで素材が見つからない場合は、プログラムで動くCG背景を使う。Pixabayの素材が必ず写真実写風になる保証はない。
- プロジェクトの \`v8\public\assets\` に自分で \`revolver.mp4\`, \`bullet.mp4\`, \`sky.mp4\`, \`clouds.mp4\`, \`apex.mp4\` を置くと、その素材を優先して背景に使用できる。
- 完成した動画: \`v8\out\magnum45.mp4\`

## 物理モデルの前提

質量 10.2 g=0.0102 kg、発射初速330m/sとして、運動エネルギー \`0.5 * 0.0102 * 330**2 = 555.39 J\`。そのため**約555J**（元の草稿の「556J」から丸めを修正）。

最大高度は**完全に鉛直、無風、質量10.2g、初速330m/s、一定空気密度1.225kg/m³、弾丸直径約9mm、抗力係数Cdを0.3〜1.0と仮定した単純化モデル**で約500〜1,100mを想定した目安。姿勢や空力特性によって結果は変わり、実際の弾道予測には使えない。最高点における「0m/s」は**鉛直速度成分**に関するもので、回転まで止まるという意味ではない。風があれば水平速度は残ることがある。

## 制限事項

このシステムは実写素材＋プログラム生成したVFXを合成する方式。**Runwayなどの有料AI映像が作るフォトリアル映像を完全再現するわけではない。** S&W M19という機種の細部や映画のキャラクターを正確に描写するための素材は含まれず、CGは一般的な回転式拳銃の図形。元のアニメや実写映画の映像素材は使用しない。

VOICEVOX:青山龍星のクレジットを動画説明欄等に表示し、各素材のライセンスと利用条件を確認すること。YouTube公開前に内容を自分で確認してください。
